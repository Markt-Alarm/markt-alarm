# Werkstern
### Webdesign und Business-Software aus Mainz

**Websites, die zeigen, was Sie können. Software, die Ihnen Arbeit abnimmt.**

Ich bin **Aaron Ansari**. Mit Werkstern entwickle ich Websites und individuelle
Webanwendungen für Selbstständige, kleine Betriebe und Praxen —
von der ersten Skizze bis zum Livegang, mit einem direkten Ansprechpartner.

[Website](https://werkstern.de) · [Praxisbeispiele](https://werkstern.de/praxisbeispiele) · [Projekt besprechen](https://werkstern.de/kontakt)

## Technik und Zusammenarbeit

TypeScript · JavaScript · React · Next.js · Tailwind CSS · Three.js

Ich beginne bei der Aufgabe im Betrieb: Informationen verständlich machen,
Kontaktwege vereinfachen und wiederkehrende Abläufe passend abbilden.
Eigene Dienstleistungsbetriebe liefern dafür praktische Erfahrung.
